# Absürt Erteleme Makinesi v2

## Giriş: Ertelemenin Kutsal Sanatı

Sevgili okur, bu repository'ye hoş geldiniz. Burada, insanlığın en kadim problemlerinden biri olan "erteleme" fenomenini, bilim ve absürtün kesişiminde yeniden tanımlıyoruz. Bu proje, sadece bir kod değil; bir yaşam felsefesi, bir manifesto, bir varoluş krizidir.

## Neden Bu Proje?

Çünkü yapacak işleriniz var. Ama yapmıyorsunuz. Ve bunun için mükemmel, bilimsel, felsefi gerekçeler üretmek zorundasınız. Bu makine, size o gerekçeleri sonsuz çeşitlilikte, Türkçe'nin en güzel halleriyle sunar.

## Nasıl Çalışır?

`erteleme.py` dosyasını çalıştırın. Makine size rastgele bir erteleme bahanesi üretir. Bu bahane o kadar ikna edicidir ki, kendinizi bile inandırırsınız. Ve sonra... yarın yaparsınız. Yarın da.

## Özellikler

- %100 çalışan kod (gerçekten!)
- Sonsuz bahane üretimi
- Aşırı ciddi ton, sıfır ciddiyet
- Gizli mesajlar (belki)

## Kurulum

Python 3 yüklü olsun yeter. Başka hiçbir şeye ihtiyacınız yok. Zaten erteleyeceksiniz.

```bash
python erteleme.py
```
